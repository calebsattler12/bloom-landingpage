Onboarding

Share your GA4 key

Two things: the Measurement ID (it starts with G-) and Viewer access for Caleb. About 8 minutes. Read-only. Do not send passwords or JSON key files.

Before you start

  • Use a laptop or desktop.
  • You need the Administrator role on the GA4 property to add users. Editor cannot add people.
  • This has to be GA4, not Universal Analytics. If you only see a UA- property, email Caleb. Bloom needs GA4.
  • Add this exact address: caleb@runbloom.ai
  • Role to pick: Viewer. Do not pick Administrator or Editor.

Copy the GA4 key

The key Bloom needs is the Measurement ID. It looks like G-XXXXXXXXXX. Also copy the numeric Property ID.

  1. Step 1

    Open Google Analytics

    Go to analytics.google.com and sign in.

  2. Step 2

    Confirm you are in the right property

    Bottom left, click Admin (gear).

    At the top of Admin, use the account and property picker. Select the account, then the GA4 property for the live marketing site. The property name is usually the company or website name. It should not say "Universal Analytics" or show a View column like the old product.

  3. Step 3

    Open the web data stream

    Still in Admin, under the Property column, find Data collection and modification, then click Data streams.

    If your Admin is a search field plus a list of cards, search for "Data streams".

    Click the web stream. It is labeled Web, and the URL should match the live site. If you have more than one web stream, pick the production site, not a staging or app stream.

  4. Step 4

    Copy the Measurement ID

    Top right of the stream details, you will see Measurement ID. It starts with G- and then a string of letters and numbers.

    Click the copy icon, or highlight it and copy. Paste it into a note. This is the GA4 key.

  5. Step 5

    Copy the Property ID too

    Go back to Admin. Under Property, click Property details (sometimes labeled Property settings).

    Copy Property ID. It is a number, like 123456789. Not the same as the G- key. Caleb needs both.

Add Caleb as Viewer

The G- key is not enough on its own. Viewer access lets Bloom open the reports.

  1. Step 6

    Open Property access management

    Admin, Property column, click Property access management.

    Do not use Account access management unless you intend to grant every property in the account. Property-only is enough.

  2. Step 7

    Add user

    Top right, click the blue +, then Add users.

    If you do not see +, you are not an Administrator on this property. Ask whoever owns the Analytics account.

  3. Step 8

    Paste Caleb's email

    Email address: caleb@runbloom.ai. Copy it. Do not retype it.

    Leave Notify new users by email checked so he gets the invite.

  4. Step 9

    Choose Viewer only

    Under Standard roles, select Viewer.

    Leave Administrator, Editor, Marketer, and Analyst off. Viewer can see reports and settings. It cannot change events, tracking, or users.

    Leave data restrictions (cost and revenue) unchecked unless your company requires it. Unchecked means Caleb can see those fields if they exist.

  5. Step 10

    Click Add

    Top right, click Add.

    You should see caleb@runbloom.ai in the list with Viewer as a direct role. If it already existed, open that row and set the role to Viewer, then save.

If you get stuck

  • No Property access management, or no +. You need the Administrator role. Editor, Marketer, Analyst, and Viewer cannot add users.
  • You only have Universal Analytics. Look for a property whose ID starts with UA-. That is the old product. Bloom needs a GA4 property (Measurement ID starts with G-). If you do not have one, say so in the email.
  • Several data streams. Copy the Measurement ID from the production web stream. Put the stream URL in the email if you are unsure.
  • Several GA4 properties. Use the one on the live marketing site. If Bloom should see more than one, add Viewer on each and send every G- ID.
  • Google says the email is invalid. It must be a Google account. caleb@runbloom.ai is valid. A company distribution list is not.
  • You found an API secret under Measurement Protocol. Skip it. Bloom does not need that secret for read-only reporting.
