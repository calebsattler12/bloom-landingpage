Share Search Console access

Search Console has no API key. You add Caleb as a Restricted user, then email him the property URL. About 5 minutes. Read-only.

Before you start

  • Use a laptop or desktop. The Search Console app is harder for this.
  • Sign in with the Google account that owns the website in Search Console. Restricted and Full users cannot add people.
  • Add this exact address: calebsattler21@gmail.com
  • Permission to pick: Restricted. Do not pick Owner. Do not pick Full unless Caleb asked for it.
  • Do not send passwords, 2FA codes, or JSON key files.

Add Caleb

Do these in order. If a screen does not match, skip to troubleshooting at the bottom.

  1. Step 1

    Open Search Console

    Go to search.google.com/search-console.

    Sign in with the Google account that manages the site. If Google asks you to pick an account, pick the one used when the site was verified.

  2. Step 2

    Pick the right property

    Top left, click the property selector. It shows a URL or a domain name.

    Choose the property for the site Bloom is working on. If you see both a domain property (sc-domain:yourcompany.com) and a URL-prefix property (https://www.yourcompany.com), pick the domain one if it exists. Otherwise pick the exact URL people type in a browser, including www or not, matching the live site.

  3. Step 3

    Open Users and permissions

    In the left sidebar, scroll to the bottom. Click Settings (gear).

    Click Users and permissions. This row only shows up for Owners. If you do not see it, you are not an Owner on this property. Stop here and ask whoever verified the site (often a developer, IT, or the agency that set Search Console up).

  4. Step 4

    Click Add user

    Top of the user list, click Add user.

  5. Step 5

    Paste Caleb's email

    In the email field, paste calebsattler21@gmail.com. Copy it. Do not retype it. A Google Group or shared inbox will fail. It has to be that Google account.

  6. Step 6

    Set permission to Restricted

    Open the permission dropdown. Choose Restricted.

    Restricted can view Performance, indexing, and most reports. It cannot add users, change settings, or verify owners. That is what Bloom needs.

  7. Step 7

    Save, then check the list

    Click Add.

    You should see calebsattler21@gmail.com in the list with Restricted next to it. Access is immediate. Caleb does not have to click a magic link first, though Google may email him.

  8. Step 8

    Copy the property name

    Look at the top-left property selector again. Copy the full property string. Examples: https://www.yourcompany.com/ or sc-domain:yourcompany.com.

    If Bloom should see more than one property (www and the apex, or a staging host you care about), add Restricted on each one and copy every property name.

If you get stuck

  • No Users and permissions. You are not an Owner. Ask the person who originally verified the site. A Restricted or Full user cannot add Caleb.
  • Add user is missing or gray. Same cause. You need Owner on that property.
  • Google says the email is invalid. It must be a Google account. calebsattler21@gmail.com is valid. A company distribution list is not.
  • You have several properties. Add Restricted on each live site Bloom should see. Put every property name in the email.
  • Domain vs URL-prefix. Domain covers http, https, www, and subdomains. URL-prefix covers only that exact protocol and host. Prefer domain when you have it.
  • The site is not in Search Console yet. Someone has to add and verify the property first. Bloom cannot do that without Owner access to the DNS or CMS. Email Caleb and say it is not set up.
